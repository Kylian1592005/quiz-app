# React Quiz App

A simple interactive quiz application built with React and Vite. Users can answer multiple-choice questions, track their progress, submit the quiz, review their answers, and retry the quiz.

## Features

- Multiple-choice questions
- Select and update answers
- Navigate between questions using Next and Previous
- Track answered questions and progress percentage
- Warning for unanswered questions before submission
- Calculate score and display quiz results
- Review answers with correct, incorrect, and unanswered status
- Retry the quiz with reset functionality
- Responsive user interface

## Tech Stack

- React
- Vite
- Tailwind CSS
- daisyUI
- JavaScript

## How to Use

1. Start the quiz and read each question.
2. Select an answer from the available options.
3. Use Next and Previous to navigate between questions.
4. Check your progress as you answer.
5. Submit the quiz when you are ready.
6. View your results and review your answers.
7. Retry the quiz to start again.
